# The Food Crush Billing

Android billing app for The Food Crush.

- Add/select items
- Cart and automatic total
- Cash / UPI / Card label
- Bill history
- Generates a clean receipt image
- Saves the bill directly to Android Gallery
- Share bill image to WhatsApp or any supported app
- No Base44, Firebase, printer or Bluetooth required

Build:
flutter pub get
flutter build apk --release

GitHub Actions workflow is included in .github/workflows/build-apk.yml.
